# CACS Africa - Site Web Institutionnel

Site vitrine pour la Chambre Africaine du Commerce et des Services (CACS).

**Démo :** [abahamou.github.io](https://abahamou.github.io)

## Technologies

* HTML5, CSS3 (Flexbox, Grid, Keyframes)
* Vanilla JavaScript (ES6+)
* FontAwesome & Google Fonts

## Fonctionnalités

* Hero Slider (tactile et clavier)
* Scroll Reveal (Intersection Observer)
* Défilement des partenaires (Marquee)
* Design responsive
